# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in OrySaaS, please **do not open a public GitHub issue**.

Instead, report it privately by email to **vincent@oryscorp.fr**, including:

- A description of the vulnerability and its potential impact
- Steps to reproduce it (a minimal example if possible)
- Any relevant logs, screenshots, or affected file/endpoint

We'll acknowledge your report as soon as possible and keep you updated as we investigate and work on a fix. Please give us reasonable time to address the issue before any public disclosure.

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

As the project is still pre-1.0, only the latest released version receives security fixes.
